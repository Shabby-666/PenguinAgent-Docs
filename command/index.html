    HuHoBotPenguin 命令列表¶

    权限列 管理员 受群配置的「管理方式」影响（/管理方式）：默认仅数据库管理员；可切换为 QQ 群主/管理员判定或双重要求。

    参数约定：(必选) [可选]

    如输入的名称带有空格，请使用英文双引号 " 包裹

    帮助¶

    命令 参数 说明 权限
    /帮助 — 列出所有内置命令、自定义命令和扩展命令 所有人
    /版本 — 查看版本信息 所有人
    /addons — 查看已安装的扩展列表 所有人

    QQ 绑定¶

    命令 参数 说明 权限
    /绑定 (游戏ID) 绑定 QQ 账号到 Minecraft 玩家（自动同步白名单） 所有人
    /解除绑定 — 解除当前绑定（自动移除白名单） 所有人
    /MC显示名称 (MC/QQ) 切换 QQ→游戏 方向的发送者名称显示 所有人
    /QQ显示名称 (MC/QQ) 切换游戏→QQ 方向的发送者名称显示 所有人

    Note

    绑定后发送 /发信息 到游戏时，发送者名称会根据绑定设置显示为游戏ID或QQ昵称。

    管理员管理¶

    命令 参数 说明 权限
    /管理方式 [QQ/手动/双重] 查看/切换本群管理员判定方式 管理员
    /加管理 (OpenId/@提及) 将指定用户添加为数据库管理员 管理员
    /删管理 (OpenId/@提及) 将指定用户从数据库管理员移除 管理员
    /查管理 (OpenId/@提及) 查询指定用户是否为数据库管理员 管理员

    白名单管理¶

    命令 参数 说明 权限
    /添加白名单 (XboxId) 向绑定服务器发送添加白名单请求 管理员
    /删除白名单 (XboxId) 向绑定服务器发送删除白名单请求 管理员
    /查白名单 [页码/关键字] 查询绑定服务器的白名单列表 管理员

    服务器状态查询¶

    命令 参数 说明 权限
    /查在线 — 查询绑定服务器的在线玩家列表 所有人
    /在线服务器 — 查询当前群可见的已连接服务器列表 所有人
    /motd (地址) 查询指定服务器的 MOTD 状态信息 所有人
    /背包查看 (玩家名) 查看指定在线玩家的背包内容（PNG 图片渲染） 管理员

    Note

    背包查看功能使用 Faithful 32x 贴图包渲染物品图标与方块预览。 贴图版权归 Faithful Resource Pack 所有，遵循 Faithful License v3。

    已知限制

    • 仅支持查看**在线**玩家的背包，离线玩家无法查看
    • 部分方块（铁砧、箱子、漏斗、床、旗帜、潜影盒、头颅等）因 Faithful 32x 无对应物品贴图，显示为 unknown.png
    • 动画贴图（如命令方块）仅渲染第一帧
    • 玩家皮肤渲染为 2D 正面视图，不支持 3D 旋转
    • 背包图片由服务端渲染，需要服务器有图形环境支持（headless 模式）

    MOTD 控制¶

    命令 参数 说明 权限
    /blockMotd — 屏蔽本群的 MOTD 功能 管理员
    /unblockMotd — 解除本群的 MOTD 屏蔽 管理员

    命令执行¶

    命令 参数 说明 权限
    /执行 (关键词) [参数...] 执行服务端自定义命令（根据命令权限判断） 所有人
    /管理员执行 (关键词) [参数...] 以管理员身份执行服务端自定义命令（无视命令权限） 管理员
    /执行命令 (命令内容) 向绑定服务器发送管理员命令并等待回报 管理员

    Note

    自定义命令支持直接使用 /<关键词> 快捷执行。 拥有管理员权限的用户会自动使用管理员权限执行。

    命令黑名单

    配置文件中的 command-blacklist 列表可以禁止通过 /执行 或 Agent run_command 工具运行指定的服务器命令。 例如禁止 /执行 op someone：在黑名单中添加 op。匹配时不区分大小写。

    群服互通¶

    命令 参数 说明 权限
    /发信息 (消息内容) 将消息转发到绑定服务器的游戏聊天（绑定用户显示游戏ID） 所有人
    /全量 [开/关] 查看/开关全量转发模式（开启后所有未命中指令的消息自动转发到游戏） 管理员

    AI Agent¶

    命令 参数 说明 权限
    /agent (任务描述) 启动 AI Agent 执行服务器管理任务 管理员
    /newsession — 清除 AI 会话上下文，下次 /agent 开始全新对话 管理员
    /stop — 紧急停止所有 AI 任务 管理员

    Note

    AI Agent 支持两种执行模式：auto（AI 直接执行命令）和 manual（管理员通过 QQ 按钮审批）。 详细文档请查看 AI Agent。

    身份认证¶

    命令 参数 说明 权限
    /认证 — 查看自己的 QQ 认证绑定状态 所有人
    /认证 (QQ号) 发起 QQ 头像自助认证 所有人
    /认证 (QQ号) (OpenId) 管理员手动完成认证绑定 管理员
    /解除认证 (OpenId) 解除指定用户的 QQ 认证绑定 管理员
    /查信息 — 查看自己的 OpenId 和群 OpenId 所有人
    /查信息 (OpenId/@提及) 查询指定用户的 QQ 绑定信息 管理员

    游戏内命令¶

    以下命令在 Minecraft 游戏内使用：

    命令 参数 说明 权限
    /qqbind (验证码) 完成 QQ 绑定的游戏内验证（需先在 QQ 端发起 /绑定） 所有人
    /at (群成员昵称) (消息) 向 QQ 群发送 @提醒消息（支持昵称自动补全） 所有人
    /huhobot (子命令) HuHoBot 控制命令 OP
    /huhobot reload — 重载配置文件 OP
    /huhobot info — 查看适配器信息 OP
    /huhobot webui — 查看 WebUI 地址和密码 OP
    /huhobot password (新密码) 修改 WebUI 登录密码 OP

    扩展系统¶

    第三方插件可通过扩展 API 注册命令，自动出现在 /帮助 和 /addons 中。

    // 注册扩展
bot.registerAddon("MyAddon", "1.0.0", "我的插件", "作者");

// 注册扩展命令
bot.registerBotCommand("MyAddon", "hello", "say Hello {params}", 0, true);

    详细文档请查看 Spigot 附属插件开发。

    自定义命令¶

    自定义命令在配置文件中定义，支持以下占位符：

    占位符 说明
    {params} 完整参数
    {group} 群 ID
    {user} 用户 ID
    {name} 绑定的 MC 玩家名（未绑定则返回 QQ 用户名）
    {nickname} 用户的 QQ 昵称
    {0}、{1} 按空格拆分后的参数
    &1、&2 按空格拆分后的参数（另一种语法）
