# 附属插件列表

本页包含一些可作为附属插件拓展 HuHoBotPenguin 功能的可用插件。

## 两种扩展方式

| 方式 | 需要编译 | 支持平台 | 入口 |
|------|---------|---------|------|
| 附属插件（jar） | 是 | 全部 | 继承/调用适配器 API，见 [适配器开发](develop/adapter-api.md) |
| 脚本插件（脚本） | 否 | 仅 Spigot / Paper | `addons/<名字>/main.js`、`main.lua` 或 `main.py`，见 [脚本扩展开发](develop/script-addon.md) |

## 添加插件

您可以在网站上添加自己的插件，注册插件中心账号即可。

## 可用插件列表

全部可用插件均已收录在附属插件中心，请前往下方站点浏览并下载。
