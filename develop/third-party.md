# 第三方适配器

本页收录社区维护的 HuHoBot 第三方适配器。

## 添加适配器

你可以把自己的适配器加到这一页：编辑 `.vuepress/data/adapters.json` 后执行 `pnpm run gen`，
或直接向 [HuHoBot.github.io](https://github.com/HuHoBot/HuHoBot.github.io/pulls) 提交 Pull Request。
